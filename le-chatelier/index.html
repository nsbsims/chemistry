How to read the graph
  • One line jumps, the others bend: that substance was added (jump up) or removed (jump down).
  • Every line jumps together: the volume changed. Compression raises every concentration, expansion or dilution lowers them.
  • No jump, lines bend smoothly: the temperature changed. This is the only change here that alters K.
  • Flat lines: the system is at equilibrium.

After any disturbance the system only partly undoes the change. Added reactant is not all used up, and a compressed gas is still more concentrated than it was.
